# ATS and One-Page Playbook

Use this guide after content is evidence-checked and targeted to a specific JD.

## Make the resume ATS-readable

- Reuse important JD keywords and job-specific terminology only where the candidate has matching evidence. Prefer the employer's natural wording when it remains factually accurate.
- Use standard section titles such as `Professional Summary`, `Experience`, `Education`, `Projects`, and `Skills`. Do not replace them with clever labels.
- Put keywords inside meaningful accomplishment statements or clearly grouped skills. Never repeat terms solely to raise a perceived match score.
- Never add hidden, white-on-white, zero-size, or off-page keywords.
- Keep names, employers, titles, dates, and skills as selectable text in a logical reading order. Avoid relying on icons, images, text boxes, tables, headers, or footers to carry essential facts.
- Export to the file type requested by the employer and confirm the exported PDF preserves visible text and order.

Treat keyword coverage as an evidence map, not an ATS score. Report unmet requirements and unsupported terms instead of fabricating a percentage.

## Fit a one-page target by relevance

Respect the user's selected page count. When the target is one A4 page, shorten content in this order:

1. Remove unrelated interests, generic qualities, references, and low-value extras.
2. Remove duplicate claims and repeated tools across profile, bullets, and skills.
3. Remove or compress old and target-irrelevant roles, projects, awards, and coursework.
4. Cut duty-only bullets and keep the strongest verified accomplishments.
5. Merge bullets that prove the same competency without losing distinct evidence.
6. Tighten wording, dates, locations, and labels; remove filler before removing evidence.
7. Shorten or remove the profile if the experience already establishes the same positioning.
8. Only then make small spacing or type adjustments that remain comfortably readable.

Do not achieve one page by shrinking text below a readable size, collapsing useful whitespace, or using margins tighter than the editor's safe print layout. Recommend two pages when one page would hide material evidence for an experienced or advanced-degree candidate.

## Verify the actual exported page

1. Export with the editor's intended page setting.
2. In the print dialog, select A4 portrait, 100% scale, and disable browser headers and footers.
3. Confirm the preview shows the selected page count with no nearly empty overflow page.
4. Inspect the top, bottom, and sides for clipping; check that section headings stay with their content and no line is truncated.
5. Open the saved PDF and confirm its page count, selectable text, reading order, links, and visual balance.
6. If it overflows, return to the relevance-based deletion order and export again.

Any character-count or content-length threshold is only an early overflow-risk warning. It cannot prove that a resume fits, because fonts, line wrapping, spacing, browser rendering, and print settings determine the final pagination. Only the exported A4 PDF is authoritative.
